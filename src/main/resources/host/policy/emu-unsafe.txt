# Host members emulated code must never run: anything that reaches outside the JVM or alters it.
# Syntax: forbidden-apis (https://github.com/policeman-tools/forbidden-apis/wiki/SignaturesSyntax).
# A bare class denies every member of the class and of its subclasses.
# Coverage modelled on the deny sets maintained by OpenSearch, Elasticsearch and Apache Lucene, extended with
# the operations those projects left to the Java SecurityManager.
